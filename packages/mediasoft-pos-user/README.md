# MediaSoft POS - User Application

Aplikasi Point of Sale untuk kasir, admin toko, dan pemilik usaha.

## Fitur

- Dashboard & Statistik
- POS/Kasir
- Manajemen Produk & Kategori
- Stok Barang
- Supplier & Pelanggan
- Pembelian & Penjualan
- Retur & Pengeluaran
- Laporan & Export
- WhatsApp Integration
- Print Queue
- Backup Data

## Development

```bash
# Install dependencies
pnpm install

# Run development
pnpm dev

# Build
pnpm build
```

## Build Desktop

```bash
# Windows
pnpm build:desktop:windows

# Linux
pnpm build:desktop:linux

# macOS
pnpm build:desktop:mac
```

## Build Mobile

```bash
# Android
pnpm build:android
pnpm android:release

# iOS
pnpm build:ios
```

## Port

Development server: `http://localhost:5173`
