# MediaSoft Developer Panel

Aplikasi khusus untuk developer dan super admin sistem.

## Fitur

- License Center & Management
- Subscription Plans
- Database Management
- API Management
- E-Commerce API Integration
- Security Management
- System Monitoring
- Activity Logs
- Backup & Restore
- Developer Tools
- System Settings

## Development

```bash
# Install dependencies
pnpm install

# Run development
pnpm dev

# Build
pnpm build
```

## Build Desktop

```bash
# Windows
pnpm build:desktop:windows

# Linux
pnpm build:desktop:linux

# macOS
pnpm build:desktop:mac
```

## Port

Development server: `http://localhost:5174`

## Note

Aplikasi ini hanya untuk desktop (Windows, Linux, macOS).
Tidak support mobile (Android/iOS).
